# Master Prompt Template

基于用户上传的原始照片进行图像编辑与风格重构。

【主体锁定】
严格保留原图中的主体身份感、年龄感、五官结构、发型、发色、表情、服装主轮廓与配色、姿势、动作、手部位置、手持物、视线方向、镜头角度、主体在画面中的位置和整体构图。不要重新设计人物。

【人物真实感】
人物保持高级真实摄影质感：自然皮肤、细腻但不过度磨皮的肤质、真实发丝、自然眼睛、真实人体比例与真实布料。不要把人物变成纸娃娃、玩偶、蜡像、卡通人物、动漫脸或光滑 CGI。

【场景保留】
识别并保留原照片的场景类型、空间结构和关键环境元素。不要把公园变成花园，不要把公交站变成童话街道，不要把上海街景变成欧洲海滨小镇。

【纸艺翻译】
将主体之外的主要环境元素重新构建成高级写实 3D 手工纸艺微缩世界。使用层叠手工纸、纹理卡纸、皱纹纸、剪纸、折纸、压纹纸与轻微手撕边缘；强调天然纸纤维、轻微不规则裁切边、可见纸张厚度、局部翘起、层层叠放和每个剪纸下方真实细小的柔和阴影。

【空间】
明确前景、中景和背景。保持原构图逻辑，在不破坏主体的前提下适度优化环境层次。

【光影】
保留原图的主光方向、天气和整体色温。使用自然真实光线、高级商业摄影、真实景深和微缩模型摄影感。不要出现均匀塑料 CGI 灯光。

【场景增强】
只添加少量符合原场景语义的纸艺细节，避免无关花海、蝴蝶、童话城堡或过度装饰。

【负面约束】
模糊、低分辨率、塑料皮肤、蜡像脸、光泽 CGI、玩偶眼、动漫脸、五官扭曲、多余手指、错误手势、物品抓握错误、重复肢体、廉价剪贴画、平面纸纹、金属塑料感、杂乱构图、无关花朵、随机文字、乱码、水印、logo。
